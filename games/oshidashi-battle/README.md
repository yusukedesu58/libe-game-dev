# おしだしバトル

フェス会場で子ども（小学校中学年〜中学生）が遊ぶ、ブラウザで動く 4 人対戦ゲーム。斜め見下ろしの円形ステージで体当たりし合い、相手を外へ押し出したら勝ち。攻撃を受けるほど ％ が増え、吹っ飛びやすくなる。

キャラは「顔画像 ＋ 名前」だけで作れる。胴体・手・足はプログラムが描いて動かすので、会場で AI に作ってもらった画像をその場で登録して使える。

## 遊び方

`index.html` をブラウザで開く（または `python3 -m http.server 8766`）。

| 操作 | ゲームパッド | キーボード 1 | キーボード 2 |
|---|---|---|---|
| 移動 | 左スティック / 十字キー | WASD | 矢印 |
| 体当たり（長押しでため） | A / X | F | K |
| ガード | B / Y | G | L |
| 参加 | A | F | K |
| 開始 | START | Enter | Enter |

- 参加画面でスティックの左右がキャラ、上下が胴体タイプ（まる・ロボ・ヒーロー・どうぶつ）。B で参加をやめる。
- 空いた枠は CPU が入る。
- のこり 3 回・90 秒。時間切れは のこり回数 → ％ の少なさ の順で勝ち。
- URL に `?demo` を付けると CPU だけの試合を流し続ける。

## キャラ登録

参加画面の右上「キャラ登録」から。画像を画面にドロップするか、Ctrl+V で貼り付けても開く。

1. 丸い枠に顔が入るよう、ドラッグで位置、スライダーかホイールで大きさを合わせる
2. 名前（8 文字まで）を入れて登録

登録キャラはブラウザ内（IndexedDB）に保存され、開き直しても残る。保存場所は開き方（`file://` と `http://localhost`）ごとに別になる。

## 構成

- `js/config.js` — 調整値（吹っ飛び・ため・ガード・試合時間など。バランス調整はここ）
- `js/input.js` — ゲームパッドとキーボードの入力
- `js/character.js` — キャラの描画（胴体タイプ、仮の顔）
- `js/roster.js` — 登録キャラの保存と名簿
- `js/register.js` — キャラ登録画面（取り込み・顔の切り抜き）
- `js/game.js` — 進行・物理・当たり判定・CPU・画面描画
